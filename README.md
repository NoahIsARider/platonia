# platonia

One page that lists every address belonging to one person: sites, works, code,
research and accounts. It is the honest alternative to a proof aggregator —
nothing to install, nothing to verify, just the list and a `sameAs` graph for
search engines.

Live: https://noahisarider.github.io/platonia/

- `index.html` — the list
- `style.css` — black paper, white ink, monospace, one lamp per address
- `DESIGN.md` — why it looks like this

No build step. GitHub Pages serves the directory as it stands.
